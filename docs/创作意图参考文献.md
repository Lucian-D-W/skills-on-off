# 创作意图参考文献

**作者思想**

我收集了一些优秀的 Skills，希望 Agent 做事时能用上它们。但工具多起来以后，我也遇到一个令人烦躁的问题：可选的办法越来越多，Agent 在选择上花的时间也越来越多。它会反复比较路线，有时还要把两条路线都试一遍。我看着它迟迟不往前走，时间和 token 却一直在消耗。

我对自己使用的 Codex 有一个很直接的感受：它有时显得胆怯，像在“左右脑互搏”。明明已经有可以采取的有效路径，还是迟迟不肯作出判断。我希望提前替它减少一些选择，把当前要用的技能选出来，让它更容易直接推进。这是我的使用体验，也是我想用这个工具改善的处境。

另一方面，外界确实有许多值得保存和使用的好技能。我希望把它们收进自己的技能库，能方便地导入、查看和管理；需要做某类事情时，也能按功能找到它们。因此，skills on-off 同时提供技能开关、项目分组和功能标签：收藏时可以保留丰富的技能，使用时再决定向 Agent 提供哪些。

**参考文献**

**1. SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks**  
Xiangyi Li 等，2026，arXiv:2602.12670，v4。[论文全文](https://arxiv.org/html/2602.12670v4)。研究在多种模型与运行框架下比较无技能和经整理的技能条件，发现技能带来的收益并不均匀；在论文的数量与复杂度分析中，至多三个模块的聚焦技能优于更大或面面俱到的组合。这为“按当前任务选择相关技能”提供了参照，数量分组结果的适用范围仍是该研究的任务与配置。

**2. How Well Do Agentic Skills Work in the Wild: Benchmarking LLM Skill Usage in Realistic Settings**  
Yujian Liu、Jiabao Ji、Li An、Tommi Jaakkola、Yang Zhang 与 Shiyu Chang，2026，arXiv:2604.04323，v1。[论文全文](https://arxiv.org/html/2604.04323v1)。研究逐步增加技能选择、检索和适配的难度，观察到技能收益随条件接近真实使用而减弱；当初始技能具备合理的相关性与质量时，针对具体任务的改写能恢复一部分收益。它帮助解释了为什么收集到技能之后，仍然需要关心选择、质量与当前任务是否匹配。

**3. Choice Overload: A Conceptual Review and Meta-Analysis**  
Alexander Chernev、Ulf Böckenholt 与 Joseph Goodman，2015，Journal of Consumer Psychology，25(2)，333–358。[期刊原文](https://doi.org/10.1016/j.jcps.2014.08.002)。这项关于人的选择行为的综述与元分析，讨论选项复杂度、决策任务难度、偏好不确定性和决策目标如何影响选择过载。复杂的选项、困难的判断和不明确的偏好，会让“尽量少花精力作决定”变得更难。它为理解使用者面对大量技能时的整理负担提供了跨领域参照。

**设计联系**

我从这些资料中形成的一个判断是：技能能不能帮上忙，与它是否适合眼前的任务有关。把越来越多的技能交给 Agent，也就把更多选择交给了它。我希望由使用者先作一部分判断，启用当前要用的技能，暂时收起其他技能。程序通过来源目录与目标目录的对应关系实现这个选择：启用时把技能复制到目标，关闭时撤去目标中的相应副本，来源仍可留作以后使用。

这些研究也让我更重视整理技能时的负担。一个 GitHub 项目可能提供多种功能，相同功能又可能分散在几个项目里。我保留项目分组，用来辨认技能的来处；同时提供功能标签，让使用者能按准备做的事情寻找技能。这两种整理方式已经体现在当前界面里。

Agent 犹豫、反复选路和双路径试验，是作者实际使用中提出的问题；论文提供了有关技能效用、选择与适配的认识。减少耗时和 token 是本项目希望达到的效果，目前尚无针对 skills on-off 本身的对照实验。关于人的选择过载研究，在这里主要用于理解人的整理与决策负担。
